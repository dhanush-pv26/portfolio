# QA Automation Portfolio

Bilingual personal portfolio (German / English) built with React, Vite, Tailwind CSS and Framer Motion.
Content is currently placeholder/reference text for a QA Automation Engineer / SDET and is meant to be edited.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Where to edit

- `src/App.jsx` → `translations` object (German `de` and English `en`): hero, about, experience, education, projects, contact
- Replace `Your Name`, `your.email@example.com`, `https://github.com/your-username` and the resume link (`#`) in `src/App.jsx`
- Replace `src/assets/profile-placeholder.svg` with a real photo and update the import at the top of `src/App.jsx`
- Page title/description: `index.html`
